Choice Under Tradeoffs

Preferences

Problem pressure: The problem is that before we talk about strategy, we need a way to say what one person is trying to get. A person may like one outcome more than another even when dollars, risk, effort, and timing are mixed together.

Mathematical handle: The object is a preference relation: a comparison rule over outcomes. When it is complete the person can compare any two outcomes; when it is transitive the comparisons do not cycle back on themselves.

Choice Under Tradeoffs

Utility

Problem pressure: The problem is that rankings are awkward to compute with. A payoff table, expected value, or equilibrium check needs numbers, not only verbal statements like this outcome is preferred.

Mathematical handle: The object is a utility function u that assigns a number to each outcome while preserving the preference ordering. Higher utility means higher in the ranking, not necessarily more money or happiness.

Choice Under Tradeoffs

Expected Utility

Problem pressure: The problem is choosing when the outcome is uncertain: a bid might win or lose, a risky action might pay off or fail, and a type may be one of several possibilities.

Mathematical handle: The object is expected utility: utility in each possible state weighted by that state's probability. It compresses a risky situation into one comparison number.

Strategic Form Games

Problem pressure: The problem is representing a situation where everyone chooses without first seeing the others' choices, yet everyone's payoff depends on the whole combination.

Mathematical handle: The object is a normal-form game: players, action sets, and payoff functions collected into a table or payoff map.

Strategic Dependence

Dominance

Problem pressure: The problem is that some choices are plainly bad no matter what the other side does. Keeping them in the analysis can distract from the strategic choices that actually need thought.

Mathematical handle: The object is a dominance comparison between two strategies across all possible actions by others.

Rationalizability

Problem pressure: The problem is deciding which strategies can be defended as sensible without requiring everyone to land on one exact equilibrium.

Mathematical handle: The object is a set of strategies that survive because each can be a best response to some belief about the other players' surviving strategies.

Equilibrium As Mutual Consistency

Best Response

Problem pressure: The problem is that a strategy is not good in the abstract. It is good against a particular opponent action or belief.

Mathematical handle: The object is the best-response set: all actions that maximize a player's payoff given the other side's action or belief.

Equilibrium As Mutual Consistency

Nash Equilibrium

Problem pressure: The problem is making a prediction that does not immediately fall apart when each participant asks, given what the others are doing, should I switch?

Mathematical handle: The object is an action or strategy profile where every player's choice is a best response to the others' choices.

Mathematical handle: The object is a payoff function where player two's payoff is the negative of player one's payoff.

Folk Theorem

Problem pressure: The problem is explaining why repeated interaction can support many outcomes, not just the one-shot equilibrium.

Mathematical handle: The object is a set of feasible and individually rational payoffs that can be sustained by equilibrium strategies when the discount factor is high enough.

Mechanisms, Auctions, And Markets

Imperfect Competition

Problem pressure: The problem is that many real markets sit between a street market with countless sellers and a single monopolist. A firm may be large enough that its price or quantity choice moves the market, but it still has rivals whose choices push back.

Mathematical handle: The object is a profit function for each firm, such as price minus cost times quantity, together with a best-response rule that says which quantity or price is most profitable against rival behavior.

Private Information And Beliefs

Screening And Adverse Selection

Problem pressure: The problem is that a price or offer can change who shows up. A seller, insurer, or bargainer may set a rule thinking about an average customer, but the people who accept are not average; they are selected by the rule itself.

Mathematical handle: The object is an expected payoff under a cutoff rule: a price or offer is accepted only by types for whom accepting is better than rejecting, so the distribution of accepted types changes with the price.

Revenue Equivalence

Problem pressure: The problem is comparing auction formats that look different: first-price, second-price, English, and others may create different bidding behavior.

Mathematical handle: The object is a theorem linking allocation rules and expected payments under assumptions such as risk neutrality, independent private values, and symmetric bidders.

Common Knowledge

Problem pressure: The problem is that coordinated action may require more than everyone privately knowing a fact. People may also need to know that others know it, and know that others know that others know it.

Mathematical handle: The object is an infinite hierarchy: the event is known, everyone knows it is known, everyone knows everyone knows it is known, and so on.
