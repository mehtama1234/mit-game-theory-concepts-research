# MIT Game Theory Concepts Research

First-principles concept research layer for MIT OpenCourseWare 14.12 Economic Applications of Game Theory, Fall 2025.

Source playlist:
https://www.youtube.com/playlist?list=PLUl4u3cNGP63quuKvMHCt3cmTmt0O2qpv

The working standard is the Stanford course concept-atlas pattern:

- keep raw transcript evidence separate from synthesis
- write plain-language explanations before formulas
- explain why the strategic problem exists in the real world
- cite transcript-backed evidence for concepts, themes, and subthemes
- validate JSON artifacts and site links before committing
