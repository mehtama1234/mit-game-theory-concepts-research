Lecture 24: Cheap Talk

Asks when costless, nonbinding messages can transmit information despite incentives to mislead.

Open YouTube lecture

Naive Starting Question

The naive question is: if talk is free and nonbinding, should we ignore it? The lecture says not always; messages can matter when incentives make truthful or partially truthful communication self-enforcing.

What This Lecture Teaches

The lecture removes signal cost and asks what communication can still do. Messages are costless and nonbinding, so credibility must come from preference alignment and receiver response.

Where The Math Enters

The math enters through sender types or states, message rules, receiver actions, and incentive constraints that make truthful or partially informative messages self-enforcing.

The mathematical object has to exist because words alone do not reveal incentives. A sentence can sound informative even when every sender type would choose it. The model needs states, sender preferences, receiver actions, messages, and beliefs so it can check whether a proposed communication rule is self-enforcing. The hard part is not decoding the literal sentence. The hard part is asking whether the sender would still want to send that sentence in the state where it is supposed to be truthful.

Worked Mini-Example

An advisor can recommend an action. If the advisor and decision maker want similar outcomes, the message may guide action; if interests conflict sharply, every type may send the same persuasive message.

Mistakes To Avoid

The mistake is to say cheap talk is always useless or always informative. The lecture's answer is conditional: speech works when incentives make the receiver's interpretation defensible.

The tempting shortcut is to label all cheap talk as empty persuasion. That fails when sender and receiver preferences are sufficiently aligned, because the sender may benefit from guiding the receiver toward a better action.

Students often get stuck by saying cheap talk is either always useless or always informative. The lecture point is conditional: credibility depends on payoff alignment and receiver response.

Durable Lesson

The durable lesson is that credibility can come from alignment, not only cost. A message works when the receiver can believe that the sender wanted to send it in exactly that state.

Reader Work

Write what each sender type wants the receiver to do, then ask what message each type would send. The work is to decide whether words separate types, pool types, or become uninformative because incentives point every type to the same message.

Reader Self-Test

Self-test: write the message each sender type would like to send, then ask what the receiver should infer. If all types send the same message, explain why the message pools information rather than revealing it. If messages differ, name the alignment that keeps them credible.

How This Lecture Hands Off

This hands off to common knowledge: communication does not only transmit facts; public messages can change what everyone knows about what everyone else knows.

How To Recognize This Later

Look for models where messages are nonbinding and the key question is whether incentives allow information transmission.

Concepts In This Lecture

Cheap Talk

Problem: The problem is whether costless messages can influence behavior when the speaker may want to mislead.

Mathematical handle: The object is a sender-receiver game where messages do not directly change payoffs but can change beliefs and actions.

What breaks without it: Without cheap talk, the course would treat all communication as either irrelevant noise or costly signaling. It would miss the middle case where aligned interests make some costless messages credible enough to affect actions.
