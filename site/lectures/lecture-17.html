Lecture 17: Bayesian Nash Equilibrium: Applications

Solves applied incomplete-information games by checking expected-payoff best responses for each type.

Open YouTube lecture

What This Lecture Teaches

The lecture uses incomplete-information representation to solve applied games. Equilibrium is now a plan for each type, and each type must be optimizing against beliefs about other types.

Where The Math Enters

The math enters through expected-payoff best responses for type-contingent strategies. Each type asks whether its assigned action maximizes expected utility given the strategy rules of others.

The mathematical object has to exist because hidden types need their own stability checks. A single action per player is not enough; each possible type needs a plan, and each plan must be optimal in expectation. Bayesian Nash equilibrium formalizes mutual consistency across those type-indexed plans. The mathematical object has to exist because platform auctions allocate attention through rankings, clicks, and quality adjustments. A simple highest-bid object misses the product being sold. The ad-auction model keeps bid, position, click probability, and value in the same incentive calculation.

Worked Mini-Example

In a first-price auction, a low-value bidder and high-value bidder follow different bidding rules. Bayesian Nash checks the incentive of each value type, not only the average bidder.

Mistakes To Avoid

The mistake is to check one action per player. With private information, the strategy is a function from types to actions, and each type needs its own deviation check.

Students often get stuck by checking only the average player. Bayesian Nash is stricter: a proposed strategy can fail because one particular type wants to deviate, even if the pooled behavior looks reasonable. Students often get stuck by seeing only bids. In sponsored search, the highest bid may not create the highest platform value if relevance and click probability differ.

How To Recognize This Later

Look for type-contingent strategies and expected-payoff best response conditions. Look for markets with ranked slots, click probabilities, quality scores, and generalized second-price style rules.

Concepts In This Lecture

Bayesian Nash Equilibrium

Problem: The problem is predicting behavior when each possible type of a player may want a different action.

Mathematical handle: The object is a strategy for every type of every player, where each type maximizes expected payoff given beliefs about other types and their strategies.

What breaks without it: Without Bayesian Nash, the course could define types and beliefs but not check whether type-contingent strategies hold together. A proposed bidding or action rule might fail for one hidden type even if it sounds plausible overall.

Open concept page

Ad Auctions

Problem: The problem is selling attention slots, not a single physical object. Position affects clicks, quality affects usefulness, and bids interact with platform rules.

Mathematical handle: The object is a sponsored-search mechanism combining bids, click-through rates, quality scores, allocation order, and per-click payments.

What breaks without it: Without ad auctions, the course would leave mechanism design at textbook allocation. It would miss how online markets mix bidding strategy with measurement, ranking rules, and platform incentives.
