Lecture 8 · Time, Threats, And Credibility, Repeated Interaction And Cooperation

Lecture 8: Backward Induction

Makes credibility calculable by solving later choices first and folding their values back into earlier decisions.

Open YouTube lecture

What This Lecture Teaches

The lecture reverses the natural storytelling order. Instead of starting at the first move, it solves the last decision first and uses that continuation value to judge earlier choices.

Where The Math Enters

The math enters as recursive value assignment. At each decision node, the player chooses the branch with the best continuation payoff, and that value is passed backward through the tree.

The mathematical object has to exist because time and information change what an action means. A flat list of actions cannot say who moved first, what was observed, or which histories a player can distinguish. The tree structure preserves those facts so later credibility and belief questions have a place to attach. The mathematical object has to exist because sequential choice has nested future problems inside current decisions. A continuation value lets the solved future replace a whole subtree. Without that object, the analyst would have to carry every possible future story instead of using the later incentive calculation. The mathematical object has to exist because a dynamic strategy includes plans for histories that may not occur. Those plans can support threats, so they must be checked. Subgame perfection formalizes the demand that continuation behavior is itself equilibrium behavior wherever a real subgame begins. The mathematical object has to exist because a known horizon changes every period’s incentives. The model needs to preserve the number of remaining rounds so last-period logic can be pulled backward. A finite repeated game is not just many one-shot games; it is a time-indexed strategic object.

Worked Mini-Example

If a seller threatens to reject a future offer but would accept once that future node arrives, the threat should not shape earlier play. Solving backward exposes that problem.

Mistakes To Avoid

The mistake is to believe every announced future action. Backward induction asks whether the action will still be optimal when the future decision actually has to be made.

Students often get stuck by assuming a tree automatically means everyone observed every earlier move. Information sets matter because the same physical history and the same known history are not always the same thing. Students often get stuck by reading the tree chronologically. Players live forward, but the analyst solves backward because later incentives determine which earlier expectations are credible. Students often get stuck by ignoring histories that do not occur in equilibrium. Those histories are exactly where empty threats hide, so the course makes students inspect them. Students often get stuck by counting repetitions rather than asking whether the relationship has a strategic future at each date. Ten known rounds and an ongoing relationship are different objects.

How To Recognize This Later

Look for histories, decision nodes, information sets, or any claim where the order of moves changes what behavior can be believed. Look for finite sequential games where the last move can be solved and folded back into earlier choices. Look for dynamic games, off-path histories, or threats where the key question is whether the promised future action would really be optimal. Look for known horizons and unraveling arguments that start at the final period.

Concepts In This Lecture

Extensive Form Games

Problem: The problem is that some games unfold over time. A later choice can depend on an earlier choice, and some players may know more about the history than others.

Mathematical handle: The object is a game tree: decision nodes, branches, histories, information sets, and terminal payoffs.

What breaks without it: Without extensive form, the course could mistake a sequential conflict for a simultaneous one. That would hide credibility, information sets, and the fact that later choices can make earlier announcements meaningful or empty.

Open concept page

Backward Induction

Problem: The problem is that early choices in a tree depend on what later players will actually do, not what they announce they might do.

Mathematical handle: The object is a game tree with continuation values assigned from the terminal nodes backward.

What breaks without it: Without backward induction, a game tree would be a picture of possible histories but not a method for evaluating them. The model could accept plans that later players would abandon once their decision node is reached.

Open concept page

Subgame-Perfect Nash Equilibrium

Problem: The problem is that Nash equilibrium can allow plans based on threats that would not be carried out if the threatened moment arrived.

Mathematical handle: The object is a Nash equilibrium that also induces a Nash equilibrium in every subgame.

What breaks without it: Without subgame perfection, dynamic models can rest on noncredible threats. A strategy profile may pass the initial Nash test only because it prescribes off-path behavior that nobody would actually choose later.

Open concept page

Finitely Repeated Games

Problem: The problem is whether repeating a game for a known number of rounds changes behavior relative to playing once.

Mathematical handle: The object is a stage game repeated T times with a known final period.

What breaks without it: Without finite repetition, students might overgeneralize from ongoing relationships and assume history always disciplines behavior. The course needs the finite case to show why the endpoint is strategically powerful.
