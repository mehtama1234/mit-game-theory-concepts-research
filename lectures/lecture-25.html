Lecture 25: Common Knowledge

Climbs from private knowledge to shared higher-order knowledge, where everyone knows and knows that others know.

Open YouTube lecture

Naive Starting Question

The naive question is: if everyone knows a fact, why is that not enough for coordination? The lecture shows that strategic behavior may depend on whether everyone knows that everyone knows it, and knows that this is shared.

What This Lecture Teaches

The lecture climbs from private knowledge to shared higher-order knowledge. Coordination may require not only that everyone knows a fact, but that everyone knows that everyone knows it, and so on.

Where The Math Enters

The math enters through recursive knowledge operators. Starting with an event, the model repeatedly applies the idea that everyone knows the event and everyone knows that others know it.

The mathematical object has to exist because coordination can depend on levels of knowledge, not only on the fact itself. Recursive knowledge operators let the course distinguish private knowledge from public assurance. That distinction explains why announcements can move behavior when private messages cannot.

Worked Mini-Example

If every firm privately hears a rule change, each may still wonder whether others heard it. A public announcement can change behavior because it also tells everyone that others heard it.

Mistakes To Avoid

The mistake is to treat true, known, and common knowledge as identical. Strategic coordination can depend on the publicness and higher-order structure of knowledge.

The tempting shortcut is to treat truth, knowledge, and public knowledge as the same thing. That fails because private receipt of the same fact can leave each player uncertain about whether others received it too.

Students often get stuck because the infinite chain sounds philosophical. The course uses it for concrete coordination: people act differently when a fact is publicly shared than when each person only privately receives it.

Durable Lesson

The durable lesson is that publicness is a strategic resource. Common knowledge turns a fact into a coordination object by making higher-order beliefs line up across players.

Reader Work

For every fact in the example, label whether it is private, mutual, public, or common knowledge. Then name the coordinated action that needs higher-order confidence. The work is to distinguish shared information from shared awareness.

Reader Self-Test

Self-test: construct a case where everyone privately knows the fact but no one knows whether everyone else knows. Then add a public announcement and explain which belief levels change. This tests the difference between truth and publicness.

How This Lecture Hands Off

This completes the course arc by returning to the central primitive: strategic behavior depends not only on payoffs and actions, but on what each player can safely believe others understand.

How To Recognize This Later

Look for coordination failures, public announcements, or arguments that depend on what everyone knows about everyone else's knowledge.

Concepts In This Lecture

Common Knowledge

Problem: The problem is that coordinated action may require more than everyone privately knowing a fact. People may also need to know that others know it, and know that others know that others know it.

Mathematical handle: The object is an infinite hierarchy: the event is known, everyone knows it is known, everyone knows everyone knows it is known, and so on.

What breaks without it: Without common knowledge, the course would miss higher-order uncertainty. Players might all know the same event, yet hesitate because they do not know whether others know, or whether others know that they know.
